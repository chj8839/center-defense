# 센터 디펜스

중앙에 고정된 캐릭터로 마우스 조준 슈팅 게임입니다.

## 실행 방법

로컬 서버로 실행 (ES 모듈 사용):

```bash
npx serve .
```

브라우저에서 `http://localhost:3000` 접속

또는 VS Code Live Server 확장으로 `index.html` 열기

## 조작

- **마우스** — 조준 & 자동 사격
- **WASD / 방향키** — 이동 범위 증강 획득 후 중앙 주변 이동

## 게임 흐름

1. **로비** — 게임 시작
2. **전투** — 적 처치 → EXP → 레벨업 → 증강 3택1
3. **레벨 10** — 보스 등장
4. **보스 처치** — 클리어 → 로비 복귀

## 증강 종류

| 증강 | 효과 |
|------|------|
| 공격력 | 데미지 +20% |
| 공격속도 | 발사 속도 +15% |
| 탄환 속도 | 탄속 +25% |
| 멀티샷 | 추가 탄환 +1 |
| 관통 | 관통 +1 |
| 치명타 | 치명타 확률/배율 증가 |
| 최대 HP | HP +25 |
| 재생 | 초당 HP 회복 |
| EXP 획득 | EXP +20% |
| 이동 범위 | 중앙 이동 반경 확대 |
| 이동속도 | 이동 속도 +30% |
| 넉백 | 적 밀어내기 |
| 산탄 | 분산 탄환 +2 |
| 오비탈 | 회전 보호구 |

## 기록

최고 레벨과 클리어 횟수는 브라우저 localStorage에 저장됩니다.
