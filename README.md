# 센터 디펜스

WASD로 이동하고 마우스로 조준하는 서바이벌 슈팅 게임입니다.  
적을 처치해 EXP를 모으고 레벨업하며 증강을 쌓아 **레벨 100 최종 보스**를 처치하면 클리어합니다.

- **온라인 플레이:** [https://center-defense.vercel.app/](https://center-defense.vercel.app/)
- **GitHub:** [https://github.com/chj8839/center-defense](https://github.com/chj8839/center-defense)

## 실행 방법

ES 모듈을 사용하므로 HTML 파일을 직접 열면 실행되지 않습니다. 로컬 서버로 실행하세요.

**Windows (간편)**

1. `start.bat` 더블클릭
2. 브라우저에서 `http://localhost:3456` 접속

**터미널**

```bash
npx serve .
```

브라우저에서 표시된 주소(기본 `http://localhost:3000`) 접속

**기타**

- VS Code Live Server 확장으로 `index.html` 열기

## 멀티플레이 (1~4인 온라인)

- **개인별** EXP / 레벨 / 증강
- **개인별** 카메라 (각자 화면)
- 한 명 사망 시 **해당 플레이어만** 게임 오버 (다른 플레이어는 계속)
- Railway WebSocket 서버 사용

### 서버 실행 (로컬)

```bash
cd server
npm install
npm start
```

기본 포트: `8080`

### 클라이언트

1. 로컬 서버로 게임 실행 (`npx serve .`)
2. [multi.html](multi.html) 접속
3. 닉네임 입력 → 방 만들기 또는 코드로 참가
4. 방장이 **게임 시작**

### Railway 배포

1. Railway에서 새 프로젝트 생성
2. Root Directory: `server`
3. Deploy 후 생성된 URL 확인 (예: `center-defense-server-production.up.railway.app`)
4. `js/network-config.js`의 `WS_URL`을 `wss://YOUR-URL` 로 수정
5. Vercel(클라이언트) 재배포

로컬 테스트 시 서버 URL: `ws://localhost:8080` (자동)

## 조작

- **마우스** — 조준 & 자동 사격
- **WASD / 방향키** — 이동 (카메라가 플레이어를 따라감)
- **모바일 (멀티터치)** — 화면 **왼쪽** 조이스틱으로 이동, **오른쪽** 터치로 조준 (자동 사격)

## 게임 흐름

1. **로비** — 최고 기록 확인 후 게임 시작
2. **전투** — 적 처치 → EXP 획득 → 레벨업 → 증강 3택1
3. **레벨 10·20·…·90** — 보스 등장 → 처치 후 전투 재개
4. **레벨 100** — 최종 보스 **최종 수호자** 처치 시 클리어 → 로비 복귀

최대 레벨은 **100**이며, 10레벨마다 고유 패턴의 보스가 등장합니다.

## 일반 적

| 적 | 특징 |
|------|------|
| 돌진병 | 기본 근접형 적 |
| 속공병 | 빠르지만 체력이 낮음 |
| 중갑병 | 느리고 단단함 (Lv.2~) |
| 사수 | 원거리 탄환 공격 (Lv.3~) |

레벨이 오를수록 적의 체력·속도·데미지가 증가하고, 스폰 간격이 짧아집니다.

## 보스

10레벨마다 다른 보스가 등장합니다. 티어가 올라갈수록 체력·데미지·속도가 강해지며, HP 50% 이하에서 **Phase 2**로 전환됩니다.

| 레벨 | 보스 | 패턴 |
|------|------|------|
| 10 | 돌진 군주 | 빠른 돌진 + 부채꼴 탄막 |
| 20 | 포격 거인 | 넓은 범위 탄막 |
| 30 | 소환 군단장 | 적 대량 소환 |
| 40 | 속공 재앙 | 고속 추격 + 연속 사격 |
| 50 | 중갑 요새 | 높은 체력, 2페이즈 전방위 탄막 |
| 60 | 사격 사령관 | 거리 유지 + 연속 사격 |
| 70 | 회오리 군주 | 회전 나선형 탄막 |
| 80 | 분열체 | 2페이즈 전방위 탄막 |
| 90 | 암흑 군주 | 조밀한 탄막 |
| 100 | 최종 수호자 | 복합 패턴 (최종 보스) |

## 증강 종류

레벨업마다 아래 증강 중 3개가 제시되며, 같은 증강은 최대 티어까지 중복 선택할 수 있습니다.

| 증강 | 효과 | 최대 티어 |
|------|------|-----------|
| 공격력 | 데미지 +20% | 16 |
| 공격속도 | 발사 속도 +15% | 16 |
| 탄환 속도 | 탄속 +25% | 12 |
| 멀티샷 | 추가 탄환 +1 | 10 |
| 관통 | 관통 +1 | 10 |
| 치명타 | 치명타 확률 +8%, 배율 +0.3 | 12 |
| 최대 HP | 최대 HP +25, 즉시 회복 | 16 |
| 재생 | 초당 HP 회복 +2 | 12 |
| EXP 획득 | EXP +20% | 12 |
| 이동속도 | 이동 속도 +30% | 12 |
| 넉백 | 넉백 강도 +40% | 10 |
| 산탄 | 분산 탄환 +2 (데미지 -10%) | 8 |
| 오비탈 | 회전 보호구 +1 | 10 |

- **클리어 횟수** — 레벨 100 최종 보스 처치 횟수
